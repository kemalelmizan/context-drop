Things to Try Right Now

  1. Peel the Book Corner into a Pushpin: Drag the folded paper corner in the top-left viewport corner. Watch it morph into a pushpin, hover over any UI element (scroll your wheel to scrub overlapping layers), and release to pin it directly—or drag it into another viewport corner to re-dock!

  3. Cross-Environment MCP Feedbacks & Diff Approval: Open the Agent sidebar, click Feedbacks to inspect simulated local, staging, and production items, ask the agent for a fix, and review/apply the staged file diff inline.
